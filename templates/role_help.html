How to use RA Duty Picking

{% if me.role == 'RA' %}
  1. Choose your building. On your first sign-in, select the building you are assigned to. An admin can correct it later.
  2. Open the duty session. Your building's active sessions appear on the Sessions page.
  3. Wait for your turn. The draft order shows who is currently picking and who is waiting.
  4. Pick one date. When your turn opens, choose any date that still has space and confirm it.
  5. Save it to your calendar. Download the all-day iCalendar file from the assignments section.
{% elif me.role == 'HRA' %}
  1. Create and open a session. Set the date range, capacity, participants, and draft order for your assigned building.
  2. The first turn starts immediately. As soon as the session is created, the first selected RA can pick.
  3. Manage the order. Defer an RA, restore them later, or manually assign a date.
  4. Correct mistakes. Change or remove any participant's assignment while respecting date capacity.
  5. Close the session. Closing stops normal RA picks while preserving the assignments.
{% else %}
  1. Create buildings. Buildings must exist before RAs can select one or HRAs can create sessions.
  2. Assign roles. New users start as RAs unless their email is listed as a bootstrap admin.
  3. Correct buildings and roles. Admin changes override an RA's one-time building selection.
  4. Manage any session. Admins can create, defer, assign, correct, close, or reopen sessions across buildings.
  5. Review the audit log. Role, building, session, deferral, and assignment changes are recorded.
{% endif %}
