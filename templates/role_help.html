How RA Duty Picking works

{% if me.role == 'RA' %}

RA permissions

  • Choose a building once on first sign-in; an Admin can correct it later.
  • See duty sessions for that building.
  • See the participant order, assignments, and remaining capacity.
  • Pick one available date when you are the current participant.
  • Download your own all-day iCalendar event.

RAs cannot create sessions, change the order, assign other people, or alter capacity.

{% elif me.role == 'HRA' %}

HRA permissions

  • Everything an RA can do, including picking when included in a session.
  • Create and immediately open sessions for the assigned building.
  • Include RAs, HRAs, and building-assigned Admins as participants.
  • Set participant order and choose weekday-first, chronological, or weekend-first date ordering.
  • Set the default capacity and override capacity for individual dates.
  • Defer or restore turns, manually assign or correct dates, and close or reopen sessions.

HRAs cannot manage another building or change user roles.

{% else %}

Admin permissions

  • Everything an HRA can do, across every building.
  • Pick normally when included in a session.
  • Create buildings and assign user roles and buildings.
  • Create, manage, close, or reopen any session.
  • Correct all assignments, date ordering, and default or per-date capacities.
  • Review the audit log for administrative and scheduling changes.
{% endif %}
